Resident Evil 2 *Steam Enhancement Pack* @ mulderland.com
------------------------------------------------------------------------------------------------------------------------

1) What this pack does:

- Downgrades the Steam version to the latest GOG version (v1.0 Hotfix 5) for better compatibility
- Fixes Steam game time tracking, Steam Overlay, Steam Input, etc.
- Fixes non-rebirth crash on saving
- Installs Classic REbirth in a new "rebirth" subfolder
- Patches the Classic REbirth executable to allow 4GB of memory
- Installs Graphical Improvements (see below) and dgVoodoo2
- Installs High Quality FMVs (see below)
- Installs High Quality Audio (see below)

------------------------------------------------------------------------------------------------------------------------

2) Details

2.1) About the Graphical Improvements

This is a mix of 3 mods:
- Resident Evil 2 HD Mod (by TeamX)
- Seamless HD Project v2 (by RESHDP)
- RE-Enhance v2 (by SonicB00M)

The first two were repacked to remove "hi-res" textures that would be overwritten by the third one.
(priority order: Resident Evil 2 HD Mod < Seamless HD Project < RE-Enhance)

------------------------------------------------------------------------------------------------------------------------

2.2) About the High Quality FMVs

There are 3 options:
- RE-Enhance FMV Pack v1.1 (by SonicB00M): currently the best available pack, in 960p
- FMVs extracted from Resident Evil 2 HD Mod (by TeamX): very good quality/size ratio, in 960p
- FMVs extracted from the Sourcenext DVD (untouched), in 480p

Is it required to install one FMVs pack, as old 240p videos doesn't work with the Sourcenext port.

------------------------------------------------------------------------------------------------------------------------

2.3) About the High Quality Audio

This is a repack of the following file, to keep only music and voice files.
http://re123.bplaced.net/board/viewtopic.php?f=22&t=308

------------------------------------------------------------------------------------------------------------------------

2.4) About the Save Crash Fix

There are two causes for the game crashing while saving:
- A missing registry key under CURRENT_USER (usually the case when using a non-admin account)
- An incorrect "Save Path" in the registry

This installer runs without administrator rights, so it is able to fix both issues.
Warning: For non-Rebirth and non-Japanese versions, the save location will always be "english\saves", even if you play
in another language.

------------------------------------------------------------------------------------------------------------------------

3) Know issues

3.1) Steam Overlay does not work

Steam Overlay should always work when using the "Original executable".
However, in Classic REbirth, dgVoodoo2 must be enabled based on testing.
(Note: Steam game time tracking works in Classic REbirth even without it.)

------------------------------------------------------------------------------------------------------------------------

3.2) I have an AMD GPU

dgVoodoo2 is highly recommended in Classic REbirth if you have an AMD GPU.

------------------------------------------------------------------------------------------------------------------------

3.3) I have random crashes

You may try disabling dgVoodoo2.
