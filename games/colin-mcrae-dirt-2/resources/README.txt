This package uses the xlive.dll from ThirteenAG's Ultimate ASI Loader to remove the GFWL dependency.

If you decide to install the real GFWL instead:
- The latest GFWL installer has been downloaded to redist\GFWL\xliveredist.nsi
- Use MulderConfig to disable XLiveless

Sign-in may not work. See the PCGamingWiki page for possible solutions:
https://www.pcgamingwiki.com/wiki/Games_for_Windows_-_LIVE#Sign-in_problems
