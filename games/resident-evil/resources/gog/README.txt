Resident Evil *GOG Enhancement Pack* @ mulderland.com
------------------------------------------------------------------------------------------------------------------------

1) What this pack does:

- Fixes the "Some of the data have been damaged" error on launch, which occurs when using a non-administrator account
- Installs Classic REbirth in your GOG installation folder (requires the japanese version)
- Installs Graphical Improvements (see below) and dgVoodoo2
- Patches the Classic REbirth executable to allow 4GB of memory
- Installs High Quality FMVs (see below)
- Installs High Quality Audio (see below)

------------------------------------------------------------------------------------------------------------------------

2) Details

2.1) About the Graphical Improvements

This is a mix of 3 mods:
- Resident Evil HD Mod (by TeamX)
- Seamless HD Project v1.1 (by RESHDP)
- RE-Enhance v2.0 (by SonicB00M)

The first two were repacked to remove "hi-res" textures that would be overwritten by the third one.
(priority order: Resident Evil HD Mod < Seamless HD Project < RE-Enhance)

Director's Cut-related content was also removed, as it is not compatible with all mods.
Upscaled videos are provided as a separate option.

------------------------------------------------------------------------------------------------------------------------

2.2) About the High Quality FMVs

There are 2 options:
- RE-Enhance FMV Pack v1.1 (by SonicB00M): currently the best available pack, in 960p
- FMVs extracted from Resident Evil HD Mod (by TeamX): good quality/size ratio, in 480p

------------------------------------------------------------------------------------------------------------------------

2.3) About the High Quality Audio

This is a repack of the following file:
http://re123.bplaced.net/board/viewtopic.php?f=21&t=296

The original package included an older build of REbirth and DualShock-related files. Only the audio and voice files were kept.

------------------------------------------------------------------------------------------------------------------------

3) Know issues

3.1) Steam Overlay does not work

Steam Overlay should always work when using the "Original executable".
However, in Classic REbirth, dgVoodoo2 must be enabled based on testing.
(Note: Steam game time tracking works in Classic REbirth even without it.)

------------------------------------------------------------------------------------------------------------------------

3.2) I have an AMD GPU

dgVoodoo2 is highly recommended in Classic REbirth if you have an AMD GPU.
Do not install another version. v2.64 is the only one that provides good results.

------------------------------------------------------------------------------------------------------------------------

3.3) I have random crashes

You may try disabling dgVoodoo2.

------------------------------------------------------------------------------------------------------------------------

3.4) The "Some of the data have been damaged" error appears again

This can happen if you launch the game with a new user account.
Re-run the MulderLoad installer from that user account, with only the "Remove admin permissions requirement" option checked.
